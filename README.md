# Price Point

This repository contains a pricing analytics project with exploratory data analysis, elasticity modeling, optimization, and reporting.

## Structure

- `data/raw/` — original simulated data
- `data/processed/` — cleaned and merged datasets
- `data/data_dictionary.md` — description of fields and modeling assumptions
- `notebooks/` — analysis and modeling notebooks
- `src/` — reusable Python modules
- `dashboard/` — BI artifact or workbook and screenshots
- `reports/` — output reports and generated figures
- `deck/` — executive presentation materials
- `requirements.txt` — Python dependencies
